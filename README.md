## 📌 Descripción
Este sistema permite gestionar los pedidos de un restaurante a través de una aplicación web sencilla, intuitiva y responsiva.  
El sistema está orientado a **administradores, cajeros y cocineros**, permitiendo optimizar el flujo de trabajo desde la creación de pedidos hasta la visualización en cocina.

---

## 🚀 Funcionalidades Principales
- **Registro y autenticación de usuarios** (Administrador, Cajero, Cocinero).
- **Gestión de productos**: crear, modificar y eliminar platos/menús.
- **Creación de pedidos** por parte de garzones o cajeros.
- **Visualización de pedidos** en cocina en tiempo real.
- **Reportes básicos** de pedidos y productos para administradores.

---

## 🛠️ Tecnologías Utilizadas
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5.  
- **Backend**: JavaScript (validaciones, lógica de negocio).  
- **Base de Datos**: Relacional (ejemplo: MySQL o SQLite).  
- **APIs Externas**: Google Maps API (opcional, para ubicación de clientes o sucursales).  

---

## 👥 Perfiles de Usuario
- **Administrador**: gestiona usuarios, productos y reportes.  
- **Cajero**: registra pedidos y procesa comandas.  
- **Cocinero**: visualiza pedidos y actualiza estado de preparación.
